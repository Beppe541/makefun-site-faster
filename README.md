A faster drop-in for makefun-site 1.0.0: the same output tree byte for byte, in about a third of the CPU time. `solve.js` is a single dependency-free ES module whose `run(input)` reimplements makefun-site's build (front matter, its Markdown subset, its template dialect, permalinks, tags, index pagination and the build report) with bulk text escaping, per-build slug memoization, single-pass Markdown rendering and chunk-joined template output.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
